# 소제목 번호와 바로가기 표시 원칙

2026-11-01 사용자의 최종 설명을 기준으로 다음 형식을 유지합니다.

- **GitHub 검토 원고:** 소제목에 01, 02 순서로 번호만 표시합니다. 글 앞에 바로가기 목록이나 별도 이동 링크를 넣지 않습니다.
- **홈페이지:** 기존 읽기 화면의 옆면 바로가기 목차를 유지합니다. 큰 화면에서는 오른쪽 목차로 해당 소제목에 이동하며 읽는 위치를 표시합니다. 작은 화면의 기존 목차 배치도 유지합니다.
- 도입부에는 번호를 붙이지 않고, 원고에 이미 적힌 번호를 중복 표시하지 않습니다.
- 홈페이지의 기존 `#part-…` 주소는 유지합니다.

이번 정리는 GitHub 검토용 문서의 표시 방식에만 적용합니다. 홈페이지의 디자인·옆면 목차·게시 상태를 다시 변경하지 않습니다. 공개 글은 278편이며 앞서 준비한 다른 10편은 검토 대기입니다.
