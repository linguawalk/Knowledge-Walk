# 소제목 번호와 바로가기 목차

2026-11-01 사용자의 요청에 따라 기존 글과 새 글의 읽기 화면에 같은 기능을 적용했습니다.

- 소제목과 목차에 01, 02 순서로 같은 번호를 표시합니다. 도입부는 번호를 세지 않습니다.
- 큰 화면에서는 글 오른쪽에 목차가 따라오고, 작은 화면에서는 본문 위에 목차를 표시합니다.
- 번호 또는 제목을 누르면 해당 소제목으로 이동하고 읽는 위치를 강조합니다. 자바스크립트가 없어도 링크 이동은 가능합니다.
- 원고에 이미 적힌 번호는 화면에서 중복 표시하지 않습니다. 기존 `#part-…` 주소는 유지합니다.

기존 2편과 게시한 10편을 화면 너비 1440·1024·768·390에서 확인했습니다. 새 검토용 10편도 큰 화면과 휴대전화에서 번호·이동·현재 위치·이미지·출처 링크를 확인했습니다. 자동 검사 35개가 통과했고, 공개 홈페이지의 이전 10편·이미지·목차 파일 23개를 대조했습니다. 현재 공개 글은 258편이며 다음 새 원고 10편은 게시 승인 대기입니다.
