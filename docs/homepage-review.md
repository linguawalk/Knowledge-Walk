# KnowledgeWalk 홈페이지 확인 안내

기존 이야기 21편을 담은 검토용 홈페이지입니다. 새 글을 더 쓰는 대신, 지금까지의 콘텐츠를 찾고 읽고 구분하는 화면을 정리했습니다.

## 홈페이지 열기

[홈페이지 압축파일 내려받기](../downloads/knowledgewalk-homepage-review.zip)

GitHub의 파일 화면에서 **Download raw file** 또는 내려받기 아이콘을 누릅니다. 내려받은 압축파일을 **모두 풀고**, 그 안의 `index.html`을 더블클릭하면 브라우저에서 열립니다. 별도 프로그램 설치나 명령어 입력은 필요 없습니다. 압축파일 안에서 HTML만 꺼내면 이미지가 보이지 않으므로 폴더 전체를 유지해 주세요.

이미지·검색 자료를 함께 넣어 인터넷 없이도 읽을 수 있게 했습니다. 이 파일은 검토용 사본이며 실제 웹주소에 게시한 홈페이지는 아닙니다.

## 구성

- **첫 화면:** 8개 분야, 대표 이야기, 소주제별 서가와 내 읽기 목록으로 가는 길.
- **소주제별 서가:** 8개 분야 아래 43개 소주제를 구분하고 각 글의 제목과 편수를 표시.
- **글 읽기:** 이미지, 본문, 확인한 근거자료와 읽음 표시.
- **내 읽기 목록:** 모든 글 / 아직 안 읽은 글 / 읽은 글을 선택.
- **검색:** 제목과 본문에서 찾기, 분야 선택.

읽음 표시는 글을 열었다는 이유만으로 자동 설정하지 않습니다. 다 읽은 뒤 직접 표시하고 필요하면 취소할 수 있습니다. 같은 웹주소와 브라우저의 로컬 저장소에만 보관하며 기기 간 공유는 되지 않습니다. 브라우저 데이터를 지우면 기록도 사라집니다. 파일을 직접 여는 경우에는 브라우저에 따라 저장 범위나 유지 여부가 달라질 수 있습니다. 저장이 막히면 안내를 표시하고 읽음 버튼을 비활성화하지만 글은 계속 읽을 수 있습니다. 읽음과 게시 승인은 별도입니다.

## GitHub에서 읽기

[분야별 서가](review/README.md) → 분야 → 소주제 → 글 순서로 들어갑니다. 예를 들어 [Cities → Europe](review/cities/europe/README.md)에 베네치아 이야기가 있습니다. 분류 변경으로 개별 Markdown 파일 위치는 바뀌었으므로 앞으로는 이 서가 주소를 시작점으로 사용해 주세요. 앞서 제공한 묶음 목록의 연결도 새 위치로 갱신했습니다.

원고 JSON은 `content/stories/<분야>/<소주제>/<글 ID>.json`, GitHub 읽기용 문서는 `docs/review/<분야>/<소주제>/<글 ID>.md`에 둡니다. 본문·출처·그림 파일을 버리지 않고 위치와 연결만 정리했습니다. 홈페이지 글 주소는 `stories/<글 ID>/index.html`을 유지하므로 나중에 분류를 옮겨도 글 주소가 바뀌지 않습니다.

## 공개 상태와 다음 단계

전체 원고는 21편이고 자료 대조 완료 18편, 추가 확인 중 3편입니다. 모두 공개 승인 전 상태를 유지합니다. 공개용 빌드는 미승인 글을 제외하며, 압축파일은 미승인 글을 포함하는 검토본입니다. 이 검토본을 인터넷에 올리면 미게시 원고도 공개되므로 실제 게시 범위와 함께 승인받은 뒤 배포합니다. 검색 제외 안내는 접근 제한 기능이 아닙니다.

운영 사이트와 도메인은 변경하지 않았습니다. 다음 단계는 완성 화면을 검토하고 웹에 게시할 범위와 주소를 결정하는 일입니다. 기존의 ‘중요한 배포는 사전 확인’ 원칙에 따라 실제 게시에는 별도 확인이 필요합니다.

## 검증 범위

기본 검사 17개로 하위 폴더 수집, 분류·원고 연결, 글 주소 유지, 미승인 글의 공개용 결과 제외와 모든 내부 연결을 확인했습니다. 브라우저 검사에서는 데스크톱·모바일 서가, 읽음 저장·취소·필터, 다른 탭의 변경 반영, 저장소 접근 차단 시 대체 안내와 이미지 로딩을 확인합니다. 검색은 별도 JSON 가져오기가 막힌 상황에서도 포함된 검색 자료로 작동하도록 구현했습니다. 클라우드의 관리형 Chromium은 `file://` 탐색을 차단하므로, 파일 직접 열기는 이 환경에서 실제 실행하지 못했습니다. 동일한 홈페이지 파일은 임시 로컬 웹서버를 통해 검사합니다.
