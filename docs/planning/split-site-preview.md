# net·kr 두 사이트 개편 미리보기

2026-11-01. 실제 도메인 전환 전 검토 화면입니다. 현재 첫 화면, 원고, 기존 글 주소, CNAME, DNS, WordPress를 변경하지 않았습니다. 다른 저장소도 수정하지 않았습니다.

- [두 사이트 안내](https://knowledgewalk.net/collections/site-redesign/index.html)
- [net — 국가와 이야기](https://knowledgewalk.net/collections/site-redesign/net/index.html)
- [kr — 발견과 지식](https://knowledgewalk.net/collections/site-redesign/kr/index.html)

두 미리보기 모두 현재 net의 별도 주소로 열립니다. kr 도메인을 연결했다는 뜻이 아닙니다. 모든 화면은 검색 수집 제외(noindex) 표시와 개편 미리보기 안내를 갖습니다. 미게시 원고는 공개하지 않습니다.

## 확인할 내용

- net: 4개 지역, 주요 국가 19개, 기타 국가, 지역에 걸친 이야기. 국가별 역사·도시·문화·생활·언어 목록. 아직 글이 없는 분류는 준비 중으로 표시.
- kr: 6개 대주제와 합의한 소주제. 출신 국가보다 글의 중심 질문을 기준으로 배치.
- net 191편 + kr 137편 = 현재 게시 승인 조건을 만족하는 328편. 각 글은 한 사이트에만 배치.
- 원고 본문, 출처, 이미지·이용 조건을 유지. 번호 소제목, 큰 화면의 오른쪽 바로가기, 모바일의 접을 수 있는 목차를 유지.
- 각 사이트의 검색, 전체 서가, 읽음 표시와 두 미리보기 간 이동.

미리보기는 현재 net과 같은 브라우저 저장소를 사용하여 기존 읽음 표시를 공유합니다. 나중에 kr의 독립 도메인으로 옮기면 브라우저의 저장소가 달라지므로 읽기 기록의 이전 방식은 별도 준비가 필요합니다.

## 재생성

```sh
python3 tools/build_split_preview.py
python3 -m unittest discover -s tests -v
```

`config/proposals/`의 배치안을 읽지만 게시 여부는 매번 원본 원고의 승인·출처 조건으로 판단합니다. 기존 사이트의 검증·글 렌더링·이미지·검색·읽음 기능을 재사용하며, 바뀐 분류는 복사한 데이터에만 적용합니다. 원본 JSON은 변경하지 않습니다.

생성 위치는 `collections/site-redesign/`입니다. 이 폴더는 미리보기를 위한 공개 파일만 포함합니다. 원고 검토 파일이나 편집 메모는 복사하지 않습니다. 이미지 파일은 기존 공개 `media/`를 공유하므로 이 폴더만 따로 복사하면 이미지가 표시되지 않습니다. 독립 도메인 배포본을 만들 때는 각 사이트에 필요한 이미지도 함께 포함해야 합니다.

현재 공개 사이트 생성기의 `--sync-root`를 실행할 필요는 없습니다. 그 명령은 이번 작업에서 사용하지 않았습니다. 새 CSS는 `tools/templates/split-preview.css`에 두어 기존 첫 화면의 스타일에 영향을 주지 않습니다.

## 다음 전환 작업

미리보기 확인 후 두 도메인을 각각 서비스할 게시 구성을 확정합니다. GitHub Pages 한 사이트의 사용자 도메인을 두 독립 사이트에 동시에 사용할 수 없으므로, 같은 저장소에서 두 배포본을 만들고 별도 게시 대상을 연결해야 합니다. 서비스 선택과 접근 권한을 확인한 뒤 DNS 값을 제시합니다.

Hostinger 화면상 kr의 `@` A/AAAA는 기존 서버를 가리키고 `www`는 kr을 따라갑니다. 이메일 레코드와 `art` 하위 도메인은 홈페이지 전환과 분리해 보존합니다. 현재 DNS의 완전한 조회·백업 및 새 게시 대상 확인 전에는 기존 항목의 삭제나 변경을 안내하지 않습니다. WordPress도 전환 확인과 백업 전에는 삭제하지 않습니다.
