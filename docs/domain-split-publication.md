# 하나의 원고, 국가별·분야별 두 사이트

2026-11-07 사용자의 적용 요청으로 공통 콘텐츠 모드를 활성화했습니다. 원문·이미지·출처는 동일 파일에서 관리하고, 승인된408편을 두 탐색 사이트에서 각각 제공합니다.421편 중 미승인13편은 양쪽 모두에서 제외합니다.

- 국가별: https://knowledgewalk.net/ —4개 지역과 국가, 역사·도시·문화·생활. 국가에 연결되지 않는 글은 공통 교양·전체 서가·검색에서 읽습니다.
- 분야별: https://knowledgewalk.net/knowledge/ —역사와 도시·문화와 예술 및 기존6개 대주제. 음악 서가는 `/knowledge/categories/arts/음악/index.html`입니다.
- 실제 knowledgewalk.kr용 독립 사이트는 `_kr-site`로 생성합니다.408편 본문과 이미지·검색·메뉴를 포함합니다. 현재 `kr_live:false`이므로 실제 kr 전환은 아직 완료되지 않았습니다.

## 한 번 편집하고 두 곳에서 읽기

`config/proposals/net-kr-story-placement.json`의 각 원고는 고유ID 하나, 국가 정보, `kr_topics` 분야 목록, `publish_sites` 두 사이트, `canonical_domain` 하나를 가집니다. 같은 글을 서로 다른 원고로 복사하지 않습니다. 국가와 직접 관련 없는 글은 국가를 추측해서 배정하지 않습니다. 에니악은 원고의 미국 개발 맥락에 근거해 미국 역사에도 연결했습니다.

〈엘리제를 위하여〉는 독일 문화 목록과 분야별 음악 서가에 함께 표시되며 양쪽에서 같은 본문을 읽습니다. 글 안의 ‘국가와 분야로 읽기’ 링크로 관련 서가를 이동할 수 있습니다. 번호 소제목·옆 바로가기·기존 원고ID와 주소를 유지합니다. 실제 도메인이 달라지면 읽음 기록은 브라우저 출처별로 저장되며, 현재 같은 net의 두 경로에서는 같은 기록을 사용합니다.

## 검색과 대표주소

국가별·분야별 검색 목록은 같은408개 승인ID를 가집니다. 문서의 동일성을 관리하기 위해 대표주소는 원고마다 하나입니다. 기존 국가 중심 원고251편은 net의 원래 주소를 유지하고 기존 분야 중심157편은 현재 도달 가능한 `/knowledge/stories/...`를 대표로 사용합니다. 양쪽 본문에 동일한 canonical을 표시합니다.

실제 kr 연결을 검증한 뒤 `kr_live:true`로 전환하면 분야 중심 원고의 대표주소가 실제 kr로 바뀝니다. 검색엔진이 canonical을 반드시 그대로 선택한다고 보장하지는 않습니다. 사이트맵에는 같은 글의 대표주소만 넣습니다. 분야별·국가별 서가 페이지는 각각의 탐색 페이지로 제공합니다.

## 주소와 이미지 호환

기존 `stories/<id>/index.html`과 임시 `knowledge/stories/<id>/index.html`에서 본문을 제공합니다. 예전 분야·소주제·묶음 링크도 유지합니다. 임시 분야별 사이트는 net의 동일 이미지 파일을 재사용해 중복 게시 용량을 줄이고, 실제 kr 업로드 산출물은 자체 이미지와 자산을 포함합니다. 원문과 미승인 자료 폴더는 공개 산출물에 포함하지 않습니다.

## 실제 kr 연결에 남은 설정

읽기 전용 Hostinger 검사42355887498은 종료코드2로 실패했습니다. 배포 도구에서 이 코드는 GitHub Actions secret `HOSTINGER_FTP_PASSWORD` 미등록을 의미합니다. 업로드 단계는 건너뛰었으며 WordPress·art·기타 기존 파일은 변경하지 않았습니다.

저장소 Settings → Secrets and variables → Actions에 해당 secret을 설정한 뒤 Hostinger 연결 검사를 통과해야 실제 kr 업로드가 가능합니다. 비밀번호를 채팅이나 저장소 파일에 적지 않습니다. 배포는 검증된 TLS 연결을 사용하고 기존 파일을 삭제하지 않습니다. 먼저 독립 사이트의 본문·이미지·검색·HTTPS를 실제 kr에서 확인한 다음 도메인 전환을 설정합니다.
