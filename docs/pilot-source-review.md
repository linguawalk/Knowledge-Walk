## 실제 열람한 자료와 기록

각 원고 JSON의 `sources`에는 실제 열람한 문서의 정확한 제목·최종 URL·확인일·확인 범위를 기록했다. 후보 URL은 `verified: false`를 유지하며 독자용 참고 자료와 섞지 않는다.

열람 증거는 [조사 기록](research/source-evidence-20261027.json)에 남겼다. HTTP 성공 상태, 응답의 SHA-256, 확인한 사실, 원문에서 확인할 수 있는 짧은 발췌를 포함한다. 원문 전체와 사진을 저장소에 복제하지 않았다. 원문은 조사 중 임시 폴더에서 열람했으며, 해당 임시 파일은 배포나 업로드 대상이 아니다.

추가한 「독서당계회도」의 열람·이미지 이용 기록은 [별도 기록](research/dokseodang-gathering-20261027.json)을 따른다. 이 경우에는 해당 소장품 페이지가 이미지의 공공누리 제1유형(출처표시)을 명시하므로, 공개 표시용 사진 한 장을 변경 없이 복사해 사용했다. 출처·소장 기관·제공 기관을 표시하며, AI 재현 그림을 사료로 대신하지 않았다.

자료를 연 것만으로 핵심 주장이 검증된 것으로 처리하지 않았다. 예를 들어 필하모니아의 오보에 소개는 이중 리드 구조를 설명하지만, 본문 텍스트에 조율 기준 선택의 근거까지 없으므로 그 글의 전체 대조는 아직 완료로 표시하지 않는다. 고궁박물관 검색 결과 중 중국 태화전의 품계석에 관한 문장은 한국 궁궐의 근거로 사용하지 않았다.

## 본문에서 바뀐 부분

- **레고:** 초안의 ‘1934년’ 단정을 삭제했다. 현재 공식 상세 연혁은 1935년 말 이름을 정하는 과정과 1936년 1월부터 공식 사용했다고 설명한다. 초안의 연도와 다르므로, 가벼운 이름 이야기에 불필요한 연도 단정은 남기지 않았다. 명칭의 LEG GODT / Play Well 뜻과 목재 장난감·돌기와 튜브 구조는 공식 상세 문서로 확인했다.
- **베네치아:** 직접 확인한 대성당의 정면 장식을 관찰 대상으로 삼았다. 기둥 위 사자와 옛 공화국 영향권의 모든 사자를 한꺼번에 설명하던 문장은 줄였다. ‘책을 펼치면 평화, 덮으면 전쟁’이라는 단순 암호식 설명은 복원하지 않았다. 공식 페이지가 전승을 소개하는 부분을 역사적 사실처럼 가져오지 않았다.
- **팝콘:** 원문이 뒷받침하는 수분·전분·압력·껍질 파열과 수확 후 수분 조절을 중심으로 고쳤다. 기존 원고의 품종별 차이·기름과 공기 가열 등의 설명은 이번에 읽은 자료만으로 충분히 대조하지 못해 제외했다.
- **이메일:** 근거가 분명한 1971년의 작업과 모델 33 텔레타이프의 기존 기호 선택에 집중했다. 상업 문서 단가 표시 등 이번 출처가 직접 다루지 않는 기원 설명은 제외했다.
- **플라밍고:** 스미스소니언의 종 안내와 해설에서 어린 새의 흰색·회색 솜털, 카로티노이드, 먹이와 깃털의 관계, 먹이 섭취 방식을 확인했다. 동물원 식단 관리에 대한 별도 주장은 빼고 확인한 메커니즘으로 설명을 좁혔다.

## 현재 접근 상태와 추가 설정

이전에 추가한 10개 도메인의 설정이 적용된 뒤 공식 사이트 본문을 읽을 수 있게 되었다. 일부 첫 요청은 오류가 났지만 공개 페이지에 일반적인 브라우저 호환 요청 헤더를 사용한 정상 HTTPS 요청으로 내용을 열람했다. 로그인, 유료 접근, 보안 확인 화면을 우회하지 않았다. Venezia Unica의 일부 응답은 HTTP 200이어도 실제 글이 없는 보안 확인용 페이지였으므로 출처로 채택하지 않았다.

궁능유적본부 `royal.khs.go.kr`는 이번 조사에서 HTTP 503을 반환했다. 왕립조폐국의 이전 FAQ 경로는 404여서 사이트맵을 통해 현재 글을 찾았으나, 확보한 글만으로 테두리의 중심 주장을 모두 대조하지 못했다.

추가 조사 후보인 `www.heritage.go.kr`, `www.yamaha.com`, `www.royalmintmuseum.org.uk`는 프록시의 연결 단계에서 HTTP 403으로 차단되었다. 기존 허용 목록을 보존하면서 이 세 도메인을 환경 설정 초안에 추가했다. 저장 성공을 확인했으나 현재 실행 환경에 적용된 것은 아니다. 환경 설정 검토·저장과 개발 환경 Publish 후 실패한 요청을 새 상태에서 확인해야 한다. 이번에 이 세 사이트의 실제 문서 내용을 읽었다고 주장하지 않는다.

## 이미지와 공개 상태

초기 8편의 삽화는 AI 설명용이다. 실제 유물·제품·장소·악기 구조를 정확하게 재현한 자료나 과학 도해로 사용하지 않는다. 새 Art 원고에는 별도로 이용 조건을 확인한 박물관의 실제 작품 사진을 넣었다. 두 종류를 각 글에서 구분한다.

`source_review`와 공개 승인은 별개다. 모든 글의 `publication_ready`는 여전히 `false`이고 `approved_by`, `approved_at`도 비어 있다. 공개용 빌드에는 0편, 검토용 빌드에는 21편이 있어야 한다. 정기 생성·예약 게시·운영 사이트 배포·도메인 변경은 실행하지 않았다.
