# 첫 시범 묶음 — 출처 검토 상태

기준일: 2026-10-27 (한국 시간). 사자 이야기 1편과 새 이야기 7편을 검토용으로 준비했다. **8편 모두 출처 원문 대조 미완료이며, 공개 게시 준비가 끝난 것이 아니다.** 내용이 상식처럼 보이거나 문체가 승인되었다는 이유로 검증을 생략하지 않는다.

## 이번에 확인한 접근 제한

Python HTTPS 요청에서 아래 사이트가 모두 프록시의 `403 Forbidden`으로 차단되었다. 사이트에 실제로 접속하거나 문서 본문을 읽은 결과가 아니다. 깊은 경로의 유효성, 문서 제목, 최신 내용도 아직 확인하지 못했다.

| 원고 | 조사 후보 | 핵심 확인 항목 |
|---|---|---|
| 궁궐의 품계석 | royal.khs.go.kr, www.gogung.go.kr | 정전 의례의 자리 배치, 관직과 품계 구분, 현장 배치와 보존 상태 |
| 베네치아의 사자 | www.basilicasanmarco.it, www.veneziaunica.it | 성 마르코의 상징, 책과 문구, 광장 기둥 위 사자 위치 |

일부 URL은 기관 첫 화면이므로 그 자체가 개별 주장의 근거가 아니다. 접근이 복구되면 정확한 문서를 찾아 열람하고 문장별로 대조해야 한다. 현재 원고 JSON의 `sources`에는 **확인 후보**만 넣었고 `verified: false`, `checked_at: null`을 유지한다.

## 환경 설정에 저장한 변경

이전에 저장된 Google Fonts 도메인 2개는 보존하고, 위 표의 조사 대상 도메인 10개만 네트워크 허용 목록 초안에 추가했다. 성공 응답으로 초안 저장을 확인했지만, 저장만으로 현재 실행 환경의 인터넷 접근이 바뀌지는 않는다. 설정의 검토·저장 및 개발 환경 Publish가 필요하다는 응답을 받았다. 이 작업은 운영 사이트의 콘텐츠 게시나 도메인 변경을 실행하지 않는다.

환경 적용 이후에는 새 상태에서 먼저 실패한 요청을 재검사하고, 그 결과에 따라 정확한 문서와 리디렉션 대상을 조사한다. 필요한 추가 도메인이 있다면 실제 오류에 근거해 판단한다. 모든 인터넷에 대한 허용이나 별도의 외부 프록시는 사용하지 않는다.

## 이미 적용한 편집 조정

- 사자 원고에서 ‘펼친 책은 평화, 덮은 책은 전쟁’이라는 통속적 설명을 삭제했다. 근거와 예외를 확인하기 전까지 그 설명 자체를 전파하지 않는다. 원래 Markdown은 집필 이력으로 보존하고 웹용 JSON을 수정했다.
- 팝콘은 내부에 눈에 보이는 작은 물방울이 있는 것처럼 읽히는 부제를 ‘수분’으로 바꿨다.
- 오보에가 절대로 음이 흔들리지 않는다는 식의 단정은 넣지 않았다.
- 레고의 라틴어 어원설, @의 중세 기원설, 특정 인물이 동전 테두리를 처음 발명했다는 이야기는 넣지 않았다.
- AI 삽화는 설명용이며 실제 유물의 글자·악기 구조·제품 결합·동물 해부 구조를 증명하는 도해로 사용하지 않는다. 특히 품계석에는 확인되지 않은 글자를 만들지 않았고, 블록 삽화는 특정 세트의 제품 이미지가 아니다.

## 남아 있는 공개 조건

1. 실제 자료를 읽고 핵심 사실을 확인한다. 필요하면 본문을 수정한다.
2. 독자가 찾아볼 수 있는 정확한 제목과 URL, 확인 날짜를 기록한다.
3. 삽화와 본문의 오해 가능성을 최종 점검한다. 구체적인 묘사가 중요하면 이용 조건을 확인한 실제 사진으로 교체한다.
4. 사용자 편집 승인과 공개 시점을 별도로 확정한다.
5. 이 단계들이 끝난 원고에만 승인·검증 표시를 채운다.

현재 공개용 빌드는 계속 빈 상태를 유지해야 한다. GitHub의 검토 문서나 화면 캡처를 보는 것은 운영 사이트 게시 승인이 아니다.
